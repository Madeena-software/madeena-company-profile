# Madeena X-Ray — Company Profile Website

Official company profile website for **PT Madeena Karya Indonesia**, a professional digital radiography manufacturer based in Jogja, Indonesia.

## About Madeena

Madeena produces digital radiography equipment using fluorescence x-ray technology with:
- Competitive pricing
- Fast diagnostic time
- Very low radiation dosage
- Integrated teleradiology system

**Flagship Product:** DDR MADEENA HF100B-MDN  
**Certification:** Ijin Edar KEMENKES RI AKD21501220581
